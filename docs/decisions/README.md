# Decisions of record

One file per decision, dated, in one shape: a header naming the date, the status, what it
touches and **the trigger that reopens it**, then the decision and the reasoning behind it. A
decision that is deliberately deferred is still recorded here, with the options and what each
costs, so it is made on purpose later rather than by accident.

This directory holds the decisions of record, starting with the ones a product built on the
starter has to settle before its first migration.
